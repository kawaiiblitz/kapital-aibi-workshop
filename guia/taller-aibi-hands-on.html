Taller AI/BI en Databricks:
dashboards y Genie

En 90 minutos vas a crear, en tu propio workspace, un dashboard AI/BI con Genie Code y un espacio de Genie para preguntarle a tus datos en lenguaje natural. Todo sobre un esquema de banca de ejemplo (clientes, tarjetas, transacciones y cobranza).

Duracion: 90 min Formato: hands-on en tu workspace Prerequisito: acceso a un workspace con un SQL Warehouse

0 Prepara tus datos

Antes de arrancar, clona el repo del taller y corre el notebook de setup. Crea 4 tablas de banca en tu workspace en menos de un minuto.

Clonar el repo y correr el setup

  1. En tu workspace: Workspace → tu carpeta → Create → Git folder (tambien aparece como Repos). Pega la URL del repo:
    https://github.com/kawaiiblitz/kapital-aibi-workshop
    Ver el repo en GitHub →
  2. La primera vez, Databricks te pide enlazar una credencial de Git (un token de GitHub). Se hace una sola vez en Settings → Linked accounts (o Git integration).
  3. Abre notebooks/00_setup_datos.sql. Cambia rp por tus iniciales en la primera celda de codigo (asi no chocas con tus companeros si comparten catalogo).
  4. Adjunta compute arriba a la derecha (un SQL Warehouse serverless o un cluster) y da clic en Run all.
Vas a ver: al final, una tabla de verificacion con 4 filas: clientes (8,000), tarjetas (10,000), transacciones (150,000) y cobranza (3,000).
Plan B (sin Git en el workspace): si el clonado se complica, abre el SQL Editor y pega el contenido de notebooks/00_setup_datos.sql directo. Mismo resultado.

1 Que son los Dashboards AI/BI y Genie

Dos formas de ver los mismos datos gobernados en Databricks, sin mover el dato a otra herramienta.

Dashboard AI/BI

Tableros gobernados

Dashboards interactivos (KPIs, graficas, filtros) que corren sobre un SQL Warehouse y leen directo tus tablas de Unity Catalog. El equivalente a lo que hoy haces en Tableau, pero nativo al lakehouse.

Genie

Analitica conversacional

Le preguntas a tus datos en espanol y te responde con tablas y graficas. Aprende el contexto de tu negocio (sinonimos, metricas) y no necesitas saber SQL.

Dos conceptos clave (en una linea)

  • SQL Warehouse: el motor que ejecuta las consultas del dashboard. Se factura por el tiempo que esta encendido (por segundo), no por consulta.
  • Genie Code: el modo agente del dashboard. Le describes lo que quieres y el construye datasets, graficas, layout y filtros por ti.

2 Features y funcionalidades clave

Lo que vas a usar hoy, y que muchas veces es lo que falta o cuesta en otras herramientas.

Construccion

Genie Code

Crea y edita el dashboard desde un prompt en lenguaje natural. Referencia tablas con @nombre.

Interaccion

Cross-filter y drill

Clic en una barra filtra todo el tablero. Drill-through y pivote para navegar del resumen al detalle.

Conversacional

Ask Genie en el dashboard

Un boton dentro del dashboard para preguntar en lenguaje natural sobre los datos que ya estan en pantalla.

Operacion

Schedules y alertas

Refrescos programados, snapshots por correo y alertas cuando una metrica cruza un umbral.

Gobierno

Permisos de Unity Catalog

El dashboard respeta los permisos de las tablas. Quien no ve la tabla, no ve el dato. Un solo modelo de seguridad.

Distribucion

Publicar y embeber

Publicas una version limpia para consumidores, y puedes embeberlo en una app o portal.

3 Crear un dashboard con Genie Code

Vas a construir un tablero de salud de cartera de tarjetas hablandole al agente. Referencia tus tablas con @ (Genie las busca en tu esquema).

  1. Menu lateral: Dashboards → Create dashboard. Selecciona un SQL Warehouse arriba.
  2. Abre el panel de Genie Code (el asistente del dashboard) y pega el Prompt 1. Deja que construya.
Prompt 1 · dashboard baseCrea un dashboard de salud de cartera de tarjetas de credito usando @clientes, @tarjetas y @transacciones. Arriba pon tarjetas de KPI: numero de clientes activos, limite de credito total otorgado, saldo total utilizado y ticket promedio de transaccion. Debajo: una grafica de barras de saldo utilizado por tipo de tarjeta, una de monto transaccionado por categoria, y una linea de monto transaccionado por fecha en los ultimos 90 dias. Agrega filtros por pais y por segmento de cliente.
  1. Cuando termine, agrega una segunda pagina con el Prompt 2.
Prompt 2 · pagina de cobranzaAgrega una segunda pagina llamada Cobranza usando @cobranza y @clientes: un KPI de monto vencido total, una grafica de monto vencido por tramo de mora, una grafica de probabilidad de pago promedio por tramo de mora, y una tabla con los 20 clientes de mayor monto vencido mostrando ciudad, segmento y ultima gestion.
Prompt 3 · pulir el formatoDa formato de moneda en pesos a todos los montos, ordena las barras de mayor a menor, ponle titulos claros en espanol a cada grafica, y usa una paleta de color consistente.
Vas a ver: un dashboard de dos paginas con KPIs arriba, graficas por tipo de tarjeta / categoria / fecha, y la pagina de cobranza. Prueba dar clic en una barra: filtra el resto del tablero (cross-filter).

Probar Ask Genie dentro del dashboard

  1. Publica el dashboard (boton Publish). Deja el toggle Enable Genie encendido.
  2. Abre Ask Genie y pregunta: cual es el saldo utilizado promedio por tipo de tarjeta?
Tip del facilitador: si Genie Code se traba en una grafica, no la borres. Dile el ajuste en lenguaje natural ("cambiala a barras horizontales", "agrupa por mes"). Edita sobre lo que ya existe. Los prompts tambien estan en prompts/genie-code-prompts.md del repo.

4 Crear un Genie Space

Un Genie Space deja que cualquier persona del negocio le pregunte a los datos en lenguaje natural. A diferencia del Ask Genie del dashboard, el Space es editable: le das contexto, sinonimos y preguntas de ejemplo.

  1. Menu lateral: Genie → New. Selecciona tu SQL Warehouse.
  2. Agrega las 4 tablas de tu esquema: clientes, tarjetas, transacciones, cobranza. Nombra el Space Analitica Comercial - Taller.
  3. En Instructions, pega el contexto de negocio (asi Genie no adivina):
Instrucciones del SpaceLos montos estan en pesos mexicanos. "Cartera" se refiere a las tarjetas de credito. "Mora" es el atraso en pagos, esta en la tabla cobranza. Un cliente "activo" es aquel con estatus = 'Activo'. Cuando alguien pregunte por "buenos pagadores", ordena por prob_pago descendente. El periodo por defecto es los ultimos 90 dias, que es lo que cubre la tabla transacciones.
  1. Agrega estas preguntas de ejemplo (sample questions), que le dan pistas a los usuarios y a Genie:
  • ¿Cuántos clientes activos tenemos por país?
  • ¿Cuál es el saldo utilizado promedio por tipo de tarjeta?
  • Monto total transaccionado por categoría en los últimos 30 días
  • ¿Qué segmento de clientes tiene mayor monto vencido?
  • Top 10 ciudades por número de transacciones
  • Probabilidad de pago promedio por tramo de mora
Tip del facilitador: este es justo el patron para migrar al equipo comercial de Tableau. El Space es su punto de entrada sin SQL, y el contexto que pongas aqui (sinonimos, metricas) es lo que hace que las respuestas sean confiables. Todo esta en prompts/genie-space.md.

5 Probar Genie

Escribe estas preguntas tal cual en tu Space (o en el Ask Genie del dashboard). Fijate en que Genie muestra el SQL que genero: puedes verificarlo y corregirlo.

  • ¿Cuántas tarjetas tipo Platino están vigentes?
  • Compara el monto transaccionado entre México y Colombia
  • ¿Cuál es el ticket promedio por canal?
  • Dame el monto vencido total del tramo "90+ dias"
  • ¿Qué categoría de gasto creció más en el último mes?
  • Muéstrame los 15 clientes con mayor límite de crédito y su saldo utilizado

Preguntas de seguimiento (Genie mantiene contexto)

Despues de una respuesta, pregunta encima sin repetir todo:

  • ahora solo para México
  • y ordénalo de mayor a menor
  • muéstralo como gráfica de barras
Vas a ver: Genie responde con una tabla o grafica y el SQL que uso. Si algo no cuadra, ajusta las Instructions del Space o marca la respuesta, y Genie mejora. Ese ciclo es como se "entrena" el contexto de negocio.

6 Preguntas y siguientes pasos

Para llevarte del taller

  • Costo vs Tableau: el dashboard se factura por el tiempo encendido del SQL Warehouse (por segundo), no por consulta, y el cache abarata los refrescos. Para comparar el gasto contra Tableau, taggea el warehouse de BI (Edit → Advanced → Tags, ej. iniciativa=bi_dashboards) y velo en system.billing.usage. Para costo por dashboard, usa system.query.history con query_source.dashboard_id.
  • Genie para el equipo comercial: el Space con buen contexto es el reemplazo natural de los reportes de Tableau para quien no escribe SQL.
  • Todo el material (notebook, prompts, esta guia) queda en el repo para que lo reuses con tus datos reales.
